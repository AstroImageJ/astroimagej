### Includes

ImageJ 1.54s and Java 27

## General

- Patches for eMudhra and Java4Shell vulnurabilities.
- Updated AIJ launcher to fix a zip file vulnurability.

## New Features

- **Local, fast plate-solving** now provided for all platforms. The Astrometry.net plate-solving engine is now included in
  AIJ and provides local plate-solving capability on all computing platforms and OSs. AIJ's astrometry setup panel has
  been redesigned to handle the internal solver implementation, while still providing the option to use the legacy web
  interface to the astrometry.net website at nova.astrometry.net, as well as to local external implementations such as
  ANSVR on Windows. Note that you will need to download "index" files to use the local solver. When you first open the
  Astrometry Setup panel (bullseye icon above image display), click the "Bundled Astrometry.net" tab at the top. Then
  click the "Manage Indexes" button at the top of the panel (if the sub-panel does not open automatically). There are several
  families of indexes available. We recommend 5200-light for gettings started. Expand that option and select file(s)
  that correspond to your image's field of view and download them. The fewer indexes that are downloaded, the faster the
  first image will solve (if you have the correct index files for your FOV). Median filtering and source finding is allocated to GPUs
  when they are available. After the first images solves, we find that all following images solve in less than 1 second
  each (although this can vary greatly depending on image size and quality, GPU use, etc).
- **Bad pixel map (BPM) support**. The initial release of BPM support is available in Import Image Sequence. Basic pixel
  patching methods are provided. These are generally based on nearby pixel algorithms such as median, nearest neighbor,
  mean, etc. 2-D Gaussian fitting to provide further bad pixel correction for pixels that fail into photometric
  apertures will be added to Multi-Aperture in an upcoming version. Both custom BPM files and LCOGT BPM HDUs are
  supported. Bad pixels and the pixels used to correct them can optionally be marked in the image overlay.
- Transit model has been updated to **Transit Model v2** from EXOFASTv2 (from occult_quad_cel.pro)
- Added support for opening LCOGT Sinistro Raw images and stitching the four quadrants together.
- Added an option to calculate background pixels from first image in sequence only (thanks to **_Gregor
  Srdoc_**; useful for some TESS FFI image analyses - not for use with ground-based time-series observations).

## Bug Fixes

- Fixed border region support in plate-solver / astrometry.
- Fixed a bug in multi-aperture [when WCS region is null](https://github.com/AstroImageJ/astroimagej/pull/90), which
  caused "searching for comp stars" to persist even when canceled (Thanks to **_David Caro_**).
- Fix slow image panning.
- Fixed escape key not being reset when importing image sequence.
- Added periodogram support
  to [ignore NaN data and bad settings ranges](https://github.com/AstroImageJ/astroimagej/pull/88) (thanks to **_Gregor
  Srdoc_**).
- WCS now updates when the slice changes but the mouse position does not.
- Fixed FITS reader bug that caused an exception when first image HDU had no data.
- v1 Transit model fix - limits on very small orbital periods have been added to avoid model small number errors. P^2 <=
  1x10^-8 set to 0.0.
- v1 Transit model fix - model values very near the start and end of transit are set to baseline (1.0) to avoid model
  small number errors.
- Added option to revert to legacy transit model v1.
